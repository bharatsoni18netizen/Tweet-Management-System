# Tweet Management System (C++)

A console-based social feed simulation built in C++ utilizing Singly Linked List data structures for dynamic post creation, real-time traversal, targeted search, and memory-safe deletion.

---

## Key Features

- **Dynamic Data Structures:** Manages feed items using singly linked list nodes instead of fixed arrays.
- **Auto ID Allocation:** Unique sequential ID tracking for each generated tweet.
- **CRUD Operations:** Supports creating, reading, searching, and deleting posts dynamically.
- **Memory Safety:** Explicit heap allocation and deallocation (`new` and `delete`).

---

## Tech Stack

- **Language:** C++
- **Core Concepts:** Object-Oriented Programming (OOP), Linked Lists, Dynamic Pointers, Memory Management
- **Supported Compilers:** GCC, MinGW, Clang, MSVC
